## WorkBuddy API 暴露调查 (23:48-00:10) — 结论: 无免鉴权本地 chat API
- 在 .109 探明 WorkBuddy 本地服务:

  - :40921 = connector-proxy MCP 服务 (给本会话用, -tools 非 chat)。

- 24878 的 token 不在: 可读配置/日志/.env/connector凭据/sidecar token/MCP token 中; OpenAPI spec 也门控。深度逆向 minified bundle 不牢靠, 放弃。
- 结论: WorkBuddy 桌面端无干净可直连的本地 chat API。官方支持路径 = 桌面设置里开启 "本地 Code API" 生成 token, 再走 :24878 HTTP; 或让 codebuddy CLI 在本机已登录上下文运行。

# 2026年5月27日 工作日志

## 问题诊断与修复

### 问题：MCP 请求包含不支持的 extra_vars 参数
- **错误信息**：400 Validation: Unsupported parameter(s): `extra_vars`
- **错误场景**：使用 neural-memory 功能时出现
- **根本原因**：MCP 配置文件中使用了 connector-proxy，但在转发请求时错误添加了 extra_vars 参数

### 解决方案
1. **清理 MCP 配置**：
   - 将 `C:\Users\wangxuan\.workbuddy\mcp.json` 从使用 connector-proxy 修改为直接使用 neural-memory MCP 服务
   - 更新命令为 `python -m neural_memory.mcp`，并设置正确的环境变量

2. **配置内容**：
```json
{
  "mcpServers": {
    "neural-memory": {
      "command": "python",
      "args": ["-m", "neural_memory.mcp"],
      "env": {
        "NEURALMEMORY_BRAIN": "default"
      }
    }
  }
}
```

3. **建议后续操作**：
   - 重启 WorkBuddy 应用
   - 重新测试 neural-memory 功能
   - 如果仍有问题，检查 MCP 服务器的日志

### 经验总结
- MCP 配置不一致可能导致参数传递错误
- 确保 proxy 模式与直接模式的选择正确
- 使用直接模式通常更可靠，避免参数转换问题
